## 开始使用

司图会在默认浏览器打开。点击「导入影像」，选择照片或文件夹。

- **地图浏览** · 读取照片的 EXIF 坐标，在三维地球上查看拍摄位置和原图。
- **本地管理** · 搜索影像、筛选缺失定位的照片。原图留在原处，司图只建立索引并生成缩略图。
- **框选导出** · 在地图上框选拍摄点，将所选原图批量复制到新文件夹。
